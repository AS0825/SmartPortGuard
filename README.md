# PortGuard

Predictive Environmental Monitoring System
for Sustainable Port Cities

## Features

- Real-time environmental monitoring
- Air quality monitoring
- PM2.5 / PM10 monitoring
- Temperature & humidity monitoring
- CO / NO₂ monitoring
- Water turbidity monitoring
- Machine learning prediction
- Pollution status classification
- Interactive dashboard
- Sensor simulator
- Flask REST API
- React frontend

## Tech Stack

Frontend:
React + Vite + Tailwind CSS

Backend:
Python + Flask

Machine Learning:
Random Forest

Database:
MongoDB

Hardware:
ESP32 + Environmental Sensors
